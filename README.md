# MIHN

A web-based platform that connects service providers with service recipients, allowing users to publish, browse, request, and manage services through a simple and user-friendly interface.

---

## Overview

MIHN is a software engineering team project developed to provide a centralized platform where service providers can offer their services and recipients can easily search, request, and rate those services.

The project follows the Software Development Life Cycle (SDLC), covering system analysis, design, implementation, testing, and documentation.

---

## Features

- User Registration & Login
- Service Management
- Browse & Filter Services
- Request Management
- Ratings & Feedback
- Provider Dashboard
- Recipient Dashboard
